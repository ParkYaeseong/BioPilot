# 3분 시연: 한국어 진행 메모

영문 대본은 `NARRATION_EN.md`, 시간표는 `storyboard.json`을 사용하세요.

첫 장면에서는 연구자가 겪는 문제와 최종 결과물을 설명합니다.
다음으로 요청과 보호 잔기, 예산을 보여줍니다.
Meta의 실제 MCP 호출과 ESM 결과를 연결해 보여주는 부분이 핵심입니다.

번호 불일치나 선택 기능의 예산 부족처럼 실제 조건이 달라졌을 때 어떻게 대응하는지 한 가지만 보여주세요.
결과 화면에서는 점수, 출처, 미확인 사항을 같이 보여줍니다.

시간 절감이나 성능 향상은 실제 측정값이 있을 때만 말합니다.
측정하지 못했다면 영문 대본의 Not yet measured 문장을 사용합니다.
사전 계산 재생은 REPLAY로 표시하고, 실시간 계산처럼 소개하지 않습니다.

마지막은 대회 중 새로 만든 부분과 재현 방법을 정리합니다.
완성된 영상의 길이, 자막, 음성과 링크 접근을 직접 확인하세요.
