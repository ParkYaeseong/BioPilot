# BioPilot Bench — New Review 포함 3분 시연 대본

2026-10-29 기준 최신 UI용입니다. 영어 제출용 내레이션과 같은 0:00–3:00 구성이며, 아래 한국어 문장은 발표 연습·내용 설명용으로도 읽을 수 있습니다.

**기본안은 실제 저장 결과 + 새 요청의 로컬 검증·실행 확인 시연입니다. 새 유료 모델 호출은 하지 않습니다.** 새 영상 파일을 생성했다는 뜻은 아닙니다.

## 전달할 핵심

연구자는 “점수가 높은 후보”만 보는 것이 아니라, Meta가 어떤 도구를 호출했는지, ESM 점수의 의미는 무엇인지, 구조에서 어디까지 확인할 수 있는지, 새 실행에 어떤 승인이 필요한지를 함께 검토합니다. 앞 100초는 이미 수행한 실제 분석의 근거를 보여주고, 다음 65초는 새 요청을 안전하게 준비하는 과정을 보여줍니다. 마지막 15초는 가치와 한계를 정리합니다.

## 촬영 준비

- Saved Review: http://127.0.0.1:8522/ — Overview에서 시작합니다.
- New Review: http://127.0.0.1:8523/ — Arm paid runs를 끈 상태로 준비합니다. 사용자에게 남은 기존 세션을 임의 초기화하지 않습니다.
- 두 화면의 창 크기·배율·Appearance를 같게 맞춥니다. 자동 테마는 그대로 쓸 수 있지만 촬영 중 OS 테마를 바꾸지 않습니다.
- 녹화 전에 무료 입력 검사와 화면 전환을 리허설합니다. 입력 문구를 미리 복사해 두되 입력·거부·확인 결과는 실제 UI에서 보여줍니다.
- 전체 guided demo를 재생한 뒤 다시 수동 시연하면 시간이 부족합니다. 이 3분 본편은 실제 컨트롤을 수동으로 조작합니다. 가이드는 별도 체험용으로 남깁니다.
- 영어 음성은 영어 대본, 영어 자막은 EN.srt를 사용합니다. 한국어 영상이면 KO.srt를 사용하고 한국어 낭독 속도로 별도 리허설합니다.

## 0:00–0:15 | 문제와 결과 소개

**화면 조작:** Overview에서 연구 목적과 후보 19개를 보여준다. REPLAY 표시를 유지하고, 제목에서 후보 요약으로 천천히 이동한다.

**한국어 설명/낭독:**

BioPilot Bench는 단백질 변이 후보를 근거와 함께 검토하는 도구입니다. 공개 Lipase A의 저장된 후보 19개와 ESM 서열 선호도를 보여줍니다. 지금은 새 모델 실행이 아니라 실제 저장 결과를 재생하고 있습니다.

## 0:15–0:35 | Meta의 실제 역할

**화면 조작:** Agent Trace에서 validate_target_context와 score_positions 기록을 차례로 연다. 공개 근거·인수·결과를 짧게 보여주고, 원문 로그 전체를 스크롤하지 않는다.

**한국어 설명/낭독:**

저장된 실행 기록에서 Meta가 MCP로 실제 요청한 도구를 확인할 수 있습니다. 먼저 표적을 검증하고, 다음으로 서열 점수 계산을 요청했습니다. 제약과 순위는 코드가 관리하고, ESM은 서열 선호도를 계산합니다. 이 기록을 여는 동작은 새 요청을 보내지 않습니다.

## 0:35–0:55 | 후보 비교와 구조 연결

**화면 조작:** Compare top three를 눌러 원래 순위와 점수 3개를 비교한다. Candidate to inspect에서 A32V를 선택하고 Inspect in Structure를 누른다.

**한국어 설명/낭독:**

원래 점수와 순위를 바꾸지 않고 상위 후보를 비교합니다. A32V를 선택한 다음 Structure를 엽니다. 후보 선택이 화면 사이에 연동되어 표와 구조를 이어서 검토할 수 있습니다.

## 0:55–1:20 | 확인된 구조 위치만 표시

**화면 조작:** A32V의 no atoms 안내와 [A32] 서열 문맥을 먼저 보여준다. Position to inspect에서 S108 · protected를 선택한다. 3D 전체 모습과 author residue 77을 보여주고 Rotate를 약 2초 사용한 뒤 정지한다. 확대가 필요하면 Focus residue 후 Fit reference로 복귀한다.

**한국어 설명/낭독:**

이 화면은 변이체 예측이 아니라 공개 실험 기준 구조입니다. A32에는 원자가 없어 위치를 만들어 표시하지 않고 서열 문맥을 보여줍니다. S108을 선택하면 구조 파일의 author 잔기 77이 강조됩니다. 보호된 촉매 잔기 세 곳은 서로 다른 색으로 표시합니다.

## 1:20–1:40 | 출처와 근거 검토

**화면 조작:** Evidence의 Structure provenance에서 source, chain A, verified_index_join과 결측 위치를 보여준다. 이어 Run provenance로 바꿔 저장 점수와 후보의 연결을 보여준다. 긴 해시를 읽거나 전체 JSON을 훑지 않는다.

**한국어 설명/낭독:**

Evidence에는 구조 출처와 체인, 체크섬, 잔기 번호 대응 상태가 기록됩니다. 실행 출처 기록은 화면의 후보를 저장된 계산 결과와 연결합니다. 이 검사는 추적 가능성을 제공하며 안정성·활성·결합 변화의 검증을 뜻하지 않습니다.

## 1:40–1:55 | 새 분석 흐름으로 전환

**화면 조작:** 사이드바 New Review 링크로 8523 화면을 연다. 미리 열어 둔 같은 창을 사용해 화면 크기를 유지한다. UNARMED와 1 Input & Validation / 2 Agent Execution / 3 Review Results를 보여준다.

**한국어 설명/낭독:**

New Review는 새 분석을 위한 별도 실행 흐름입니다. 입력 검증, 에이전트 실행, 결과 검토의 세 단계로 구성됩니다. 저장 결과 탐색과 달리, 명시적으로 승인한 요청을 실행할 수 있습니다.

## 1:55–2:15 | 보호 잔기 거부 시연

**화면 조작:** Arm paid runs를 끈 상태로 Review S108A for sequence plausibility. 를 입력해 보낸다. Protected catalytic site 거부 문구와 그대로인 Runs left를 2~3초 보여준다. 입력 예시 버튼은 초안만 채우므로 실제로 전송해야 한다.

**한국어 설명/낭독:**

먼저 S108A 검토를 요청합니다. 로컬 가드는 모델 요청을 보내기 전에 이 보호 잔기 변이를 거부합니다. 이것은 실제 입력 검사이며 새로운 Meta 판단은 아닙니다. 잔기를 보호한다는 사실만으로 기능 유지가 증명되지는 않습니다.

## 2:15–2:45 | 정상 요청과 실행 승인 조건

**화면 조작:** Review A32V for sequence plausibility. 를 보내 VALIDATED를 확인한다. Confirm this review에서 full-reference 위치 32, 현재 checkpoint, 실제 화면의 remaining_runs/max_model_requests_per_run, provider_cost unknown을 보여준다. Arm paid runs와 비용 확인은 체크하지 않고 Execute approved review가 비활성인 채로 멈춘다. 제한 숫자는 녹화 화면 값만 읽는다.

**한국어 설명/낭독:**

이제 A32V를 입력합니다. 로컬 검증은 분석을 준비할 뿐 실행하지는 않습니다. 확인 화면에는 전체 기준 서열 위치, 체크포인트, 호출 제한과 미확인 비용이 표시됩니다. 새 실행에는 실행 허용, 비용 확인, Execute 버튼 클릭이 필요합니다. 이번 영상에서는 실제 실행 전에 멈춥니다.

## 2:45–3:00 | 핵심 가치와 한계

**화면 조작:** 승인 전 확인 화면을 유지하며 마무리한다. 마지막 3초에는 BioPilot Bench 이름과 Saved evidence → Human review → Explicit execution 문구만 간결하게 겹친다. 새 완료 결과나 성능 수치를 만들지 않는다.

**한국어 설명/낭독:**

저장된 근거의 탐색과 새로운 실행을 명확하게 구분합니다. ESM 서열 선호도는 실험적 내열성이나 생물학적 개선의 증거가 아닙니다. BioPilot은 연구자의 판단을 유지하면서 후보 검토 과정을 확인 가능하게 만듭니다.

## 이렇게 구성한 이유

- 먼저 실제 결과를 보여줘 무엇을 검토하는 도구인지 이해시킵니다.
- Meta는 허용된 도구를 선택하고 공개 근거를 설명하며, ESM과 코드가 계산·가드·순위를 담당한다는 역할을 실제 trace로 보여줍니다.
- Structure는 후보를 검토하는 주요 기능입니다. A32 결측과 S108의 정확한 대응을 함께 보여주면 “없는 좌표를 만들어내지 않는다”는 점도 전달됩니다.
- New Review는 보호 잔기 거부 → 정상 입력 → 명시적 실행 확인 순서입니다. 입력 전송과 유료 실행이 다른 행동임을 화면으로 확인시킵니다.
- 새 실행 전 멈추는 기본안이어도 앞부분의 실제 Meta/MCP 기록은 보여줍니다. 다만 이것을 새 요청이 방금 완료된 장면처럼 편집하지 않습니다.

## 실제 New Review 실행까지 넣으려면

해당 호출 승인을 받은 별도 촬영본이 필요합니다. 실제 모델·실행 ID·점수 파일과 반환 상태를 확인한 후 2:15–2:45 구간을 교체합니다. 대기 시간을 줄이면 편집 사실을 표시하고, 실패·부분 완료를 완료처럼 바꾸지 않습니다. 기존 테스트용 synthetic_fixture 결과를 실제 모델 결과로 사용하지 않습니다. 그 경우 “이번 영상에서는 실제 실행 전에 멈춥니다”라는 문장과 자막도 함께 바꿉니다.
