# Recording checklist

Before recording: verify actual Meta model/account, working MCP tool call, genuine ESM artifact,
approved public input, stable state, secrets hidden and source badges visible. Prepare a real replay
backup labeled as such. Keep evaluator data out of the model session.

During recording: show the problem, one request, one meaningful decision branch and one reviewable
output. Explain what was built during the event. Show a measured comparison only when it exists.
Leave scientific caveats adjacent to the result. Avoid an unreadable terminal scroll or fabricated speed.

After recording: inspect actual file duration/audio and captions; trim waiting transparently; verify
link access and repo setup; check official final form requirements. A timeline test does not test an
exported video. Do not upload or submit without explicit authorization.
