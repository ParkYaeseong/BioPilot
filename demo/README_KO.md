## 앱에서 저장 결과 확인

README의 설치 후 통합 워크벤치를 실행하면 저장 결과를 열 수 있습니다.
Overview / Candidates / Structure / Agent Trace / Evidence에서 결과를 검토합니다.
저장 결과 탐색은 새 API 호출이나 GPU 계산을 시작하지 않습니다.

`artifacts/`에는 실제 실행의 휴대 가능한 재생본과 저장된 공개 구조·예측 결과가
있습니다. 파일 해시와 실행 출처를 보존하므로 이 폴더는 실행 패키지에 필요합니다.
새 모델 실행에는 별도 설정과 명시적 승인이 필요합니다.

초기 대본과 시연 기획은 [Git 이력](https://github.com/ParkYaeseong/BioPilot/tree/0086ef9/docs/archive/demo)에 보존합니다.
