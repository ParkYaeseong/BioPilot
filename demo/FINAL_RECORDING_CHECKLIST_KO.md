# 최종 3분 촬영 체크리스트

촬영 본편은 [최신 한국어 대본](REVIEW_FLOWS_180S_KO.md)과
[영어 대본](REVIEW_FLOWS_180S_EN.md)을 사용합니다. 예전 `LOCAL_DRAFT.mp4`는 과거 초안이며,
현재 통합 UI를 촬영한 최종 영상으로 제출하지 않습니다.

## 녹화 전

- [ ] 1920×1080 또는 1280×720 고정 창, 브라우저 배율 100%, 읽기 쉬운 OS 배율을 선택합니다.
- [ ] 테마를 하나로 고정하고 알림·개인 계정·터미널·인증정보가 화면에 나오지 않게 합니다.
- [ ] 8522의 New review를 시작 화면으로 준비합니다. 튜토리얼은 종료합니다.
- [ ] `reference/lipase_full_212.fasta`를 파일 선택 창에서 바로 고를 수 있게 준비합니다.
- [ ] Recent reviews의 **COMPLETED** 기록과 PARTIAL 기록을 구별합니다.
- [ ] 완료 실행은 `14014be81e934c0ab4236268d013ad19`, Meta 3회, 실제 45.48초입니다.
- [ ] 새 실행 없이 촬영한다면 허용 체크박스와 Execute를 누르지 않습니다.

## 촬영 순서

| 시간 | 직접 보여줄 행동 | 전달할 핵심 |
|---|---|---|
| 0–15초 | New review 입력/요청 화면 | 누구의 어떤 검토를 돕는가 |
| 15–35초 | FASTA 업로드, S108A 검증 거부 | 모델 호출 전에 코드가 규칙을 적용 |
| 35–55초 | A32V 검증, 파일명·위치·호출 상한 | 승인 전 입력과 실행 범위 확인 |
| 55–75초 | 실제 완료 기록으로 명시적 컷 전환 | Recorded execution · 45.48s elapsed · waiting omitted |
| 75–100초 | Candidates 상위 3개 비교, A32V 선택 | 저장된 19개 대안과 공통 순위 정책 |
| 100–125초 | Structure, A32 원자 없음, S108 강조, 짧게 회전 | 번호 대응과 구조 시각화의 한계 |
| 125–145초 | Agent Trace 도구 2개 확인 | Meta는 도구 선택/설명, 코드는 계산/순위 |
| 145–165초 | Evidence 입력·결과 영수증 | 입력에서 결과까지 확인 가능한 근거 |
| 165–180초 | 같은 완료 결과 다시 열기 | 재호출 없는 검토와 ESM 점수의 한계 |

마우스는 설명하는 대상에 맞춰 움직이고, 스크롤·3D 회전 후에는 멈춰 읽을 시간을 줍니다.
9단계/5단계 튜토리얼 전체를 본편에 넣지 않습니다. 구조 회전을 전체 시연의 중심으로
삼지 않습니다. 가짜 Execute 클릭·진행률·모델 판단을 합성하지 않습니다.

- [ ] 실제 음성과 자막 싱크, 작은 글씨, 첫/마지막 프레임과 오디오를 전체 재생해 확인합니다.
- [ ] 편집한 실행 구간과 저장 결과에는 REPLAY/Recorded execution 표시를 유지합니다.
- [ ] “ESM preference ≠ experimental thermostability/activity” 한계를 읽을 수 있게 남깁니다.
- [ ] 최종 영상 경로/해시/길이/음성 검토 결과를 제출 기록에 추가합니다.
- [ ] 게시 승인 후 영상·저장소 링크를 로그아웃 상태에서 열어 봅니다.
- [ ] 공식 최종 제출 폼의 영상 길이·공개 접근·기여자·재사용 요구를 확인합니다.

현재 체크박스는 준비 목록이며 완료 증거가 아닙니다. 저장소 공개·영상 게시·대회 제출은
수행하지 않았습니다. 새 유료 실행을 녹화하려면 기존 남은 허용량을 임의 초기화하지 말고
별도 승인한 실제 실행으로 진행합니다.
