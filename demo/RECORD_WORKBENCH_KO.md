# 검토 화면 연속 녹화 안내 — 2026-10-28

목표는 연구자가 과제·제약을 확인하고, 실제 저장된 Meta 도구 호출과 후보 근거를
검토하는 흐름을 한 번의 화면 조작으로 보여 주는 것입니다. 저장된 실제 실행은
화면에 계속 **REPLAY / SAVED RUN**으로 표시합니다. 별도의 로컬 입력 검사는 실제
동작이지만 새 Meta 응답이나 새 ESM 계산이 아닙니다.

프로젝트 루트의 PowerShell에서 기존 설치 환경으로 실행합니다.

```powershell
.venv/Scripts/python.exe -m streamlit run app/viewer.py -- --artifact demo/artifacts/sequence_review.replay.json
```

브라우저는 localhost만 사용하고, 1280×720 또는 1440×900에서 글자와 선택 항목이
읽히는지 먼저 확인합니다. 화면·시스템 알림에 계정 키나 무관한 파일이 보이지 않게
준비합니다. 녹화 중에는 새 제공자 호출·모델 다운로드·GPU·외부 업로드를 실행하지 않습니다.
