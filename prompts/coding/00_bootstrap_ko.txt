수정본의 원칙은 다음과 같습니다.
- ESM 점수는 서열 모델의 선호도이며 T50·활성·용해도를 직접 예측한 값이 아닙니다.
- 212개 기준 서열과 181개 성숙 서열의 대응을 확인하고 전체 기준 서열 번호를 사용합니다.
- 기본 촉매 보호 위치는 전체 기준 서열 S108·D164·H187입니다. 이것이 기능 유지의 증거는 아닙니다.
- PDB 원자 좌표 대응은 아직 미확인입니다. 실제 mmCIF를 검증하기 전에는 구조 기반 계산을 차단합니다.
- T50는 등록된 시험 조건의 지표입니다. 데이터의 중앙값 분류를 야생형 대비 개선으로 해석하지 않습니다.
- 원자료와 ProteinGym 자료의 개수 차이는 원인을 추정하지 말고 변이별로 대조합니다.
- Meta와 Biohub Atlas를 구분하고, 기존 API 설정은 계정에서 확인하기 전까지 활성화하지 않습니다.
- 정답과 평가용 메타데이터, 원논문의 결과를 예측 에이전트에게 제공하지 않습니다.
- 생물학적 등록 B0와 실제 기본 모델 평가 B1을 화면 개발보다 먼저 진행합니다.

명시적인 추가 승인이 없으면 유료 API 호출, 모델 다운로드, GPU 생성, 외부 서열 업로드, 배포, 저장소 공개나 대회 제출은 하지 마세요. 비밀키를 출력하지 마세요.

점검 후 현재 구현과 설계만 있는 부분, 통과한 검사, 미확인 생물학적 항목, 다음 B0 작업의 정확한 파일 경로를 한국어로 보고하세요. 자료에 이미 있는 내용을 다시 묻지 말고, 환경에서 확인할 수 없는 사항은 미확인으로 남기세요.
