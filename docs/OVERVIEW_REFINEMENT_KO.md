# Overview 우선 UI 변경 — 2026-10-29

## 후속 검증 완료

IAB 검증을 재개해 실제 Overview 이미지를 확보했고 기존 실패를 해결했습니다.
759개 테스트 통과,2개 건너뜀. Auto 기본값과 간소화 메뉴를 적용했습니다.
이하 중단 기록은 당시 상태이며 최신 근거는 `validation/responsive_chrome_20261029.json`입니다.

## 반영한 내용

화면 순서를 `Overview → Candidates → Agent Trace → Evidence → Input & Diagnostics`로
정리했습니다. Overview는 현재 연구 범위, 저장 후보 19개, 실제 ESM 상위 결과,
Meta의 저장 실행 단계와 미검증 사항을 먼저 보여 줍니다. 저장 원본에 없는 목표는
새로 만들어 넣지 않았습니다.

후보 비교·CSV는 Candidates에 보존했습니다. 기존 Structure는 Evidence 안의
`Reference mapping & saved structures`로 옮겼습니다. 번호 대응 확인, 실험 참조
구조, 별도 계산된 저장 예측 구조를 구분하며 원자 기하·변이 효과 검증으로 표현하지
않습니다. FASTA/mmCIF 업로드와 고급 좌표 진단은 마지막 화면 내부에만 있습니다.

가이드는 영어 9단계입니다. Overview부터 실제 화면을 전환하고, 후보 3개 선택,
저장 호출 2개 검사, 근거·번호 대응, A32V 통과와 S108A 차단을 수행합니다. 종료하면
시작 전 화면·입력·후보 선택·Evidence 하위 선택을 복원합니다. 별도 LIVE 대화창은
링크로만 열며, 재생 조작에는 API/GPU 실행 경로가 없습니다.

## 검증 및 시각 검증의 한계

Overview·업로드 위치·새 화면 순서의 최초 검사 5개가 실패한 뒤, 구현 후 모두 통과했습니다.
가이드 단위·workspace를 포함한 묶음은 19개, 기존 viewer 두 파일은 49개 통과했습니다.
기존 과학·참조·검증 파일 135개는 SHA256 비교에서 전부 동일했습니다.
최종 전체 회귀는 **750개 통과, 1개 실패, 2개 건너뜀**입니다. 실패 1개는 실제 Overview
썸네일 미확보 검사이며 그대로 유지했습니다. 패키지 검사 **1,967개 통과, 실패 0**입니다.
정확한 명령과 소요 시간은 STATUS와 새 검증 영수증에 기록했습니다.

실제 변경 전 데스크톱·모바일 및 변경 후 데스크톱 진단용 캡처를
`local_artifacts/overview_refinement_20261029/`에 보존했습니다. 변경 후 캡처에 브라우저
렌더링 잘림/중복이 있어 완성 화면의 증거로 쓰지 않습니다. 이후 브라우저 제어가
현재 URL을 충분히 확인할 수 없다는 보안 오류로 종료됐습니다. 추가 UI 조작이나
다른 자동화 경로로 우회하지 않았습니다.

따라서 390/599/1280px의 모든 화면·테마 검증, 새 Overview 단계의 실제 썸네일,
최종 비교 캡처는 미완료입니다. 기존 단계 이미지 8개와 원본 녹화는 보존했습니다.
부족한 화면을 생성 이미지나 다른 화면으로 대체하지 않습니다. 180초 문서는 계획이며
새 3분 영상을 녹화했다는 뜻이 아닙니다.

생물학적 효과·원자 기하·깨끗한 별도 환경 재현·실제 청구 비용 검증 상태는 그대로입니다.
저장소 공개 전환과 대회 제출은 수행하지 않았습니다.
